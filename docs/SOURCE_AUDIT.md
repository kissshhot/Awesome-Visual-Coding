# Source Audit

Latest review and inclusion cutoff: **2026-10-14**. **36 research entries; 26 M and 10 A; 7 D system resources (6 open-source, 1 hosted).**

This is a cumulative review. Existing research records retain their 2026-10-10 review dates; eight research additions and six pinned open-source documentation reviews are dated 2026-10-14. Stitch retains its 2026-10-10 announcement review.

## Provenance and Review Method

The formatting reference is the local Awesome-OPD commit `5d575fc`, inspected using read-only Git commands. No files in that repository were changed. No applicable AGENTS.md or .agents/skills files were found in the task directory, its inspected ancestors or the template tree. The new inventory and taxonomy are original to this catalog.

Primary arXiv records were opened directly for titles, complete author lists, first submission dates, revision histories and abstracts. Versioned HTML or PDF was retrieved; M applies only to the specific passages actually inspected below, not to the entire downloaded text. A remains abstract-level even where a full-text file was obtainable. Complete paper texts are not redistributed in this repository. Metadata response hashes and M full-text response hashes in [catalog.json](../data/catalog.json) identify retrieval bytes, not cryptographic proof of scientific correctness or independent time attestation.

Searches covered screenshot/design-to-code, UI/web reconstruction, layout planning, visual editing, render-and-refine, visual reward learning, and multi-turn benchmarks, with backward links to early work and forward searches into 2026. Queries included the named works and phrases such as “visual coding render refine UI code generation 2026”, “screenshot to code benchmark”, and “visual code editing”. Search results and secondary lists were discovery aids only. Paper claims in this repository are grounded in opened primary records or the named original sections, not search snippets.

This was a selective review. It does not certify exhaustive recall, experimental reproducibility, code quality, actual dataset accessibility, data licenses, or the reliability of model-based judges. No models, source projects, benchmarks or paid services were run. External HTTP availability is recorded separately from content inspection in [VALIDATION.md](VALIDATION.md).

## Material Version and Scope Decisions

- DCGen v3 has a revised full-text title and generates code per segment. The abstract page's citation metadata still carried the earlier title. The audit follows the v3 full text, and both summaries explain the mechanism change.
- UI2Code^N v4 has a revised title and foregrounds Relative Visual Policy Optimization. Earlier title text and v1 claims were not silently treated as the reviewed version.
- Interaction2Code v3 has a revised title and expanded author list; the primary v3 record supersedes discovery results showing v1 metadata.
- Design2Code uses the v3 title and complete six-author list. Dataset and benchmark assets are not counted again as separate papers.
- WebSight is the screenshot–HTML dataset paper, not the unrelated web-navigation system with the same name. Sketch2Code identifies the Ryan Li, Yanzhe Zhang and Diyi Yang benchmark, not Microsoft's product or unrelated papers.
- ReLook explicitly separates its training critic from its critic-free inference. Vision-Guided Iterative Refinement starts from text but qualifies through rendered output feedback. WebVIA uses DOM as well as screenshots during exploration.
- 1D-Bench v3 treats the exported intermediate representation as potentially faulty. TaoD2C-Bench was submitted on 2026-10-07, within the cutoff. Their metadata inputs should not be hidden in screenshot-only comparisons.
- Sketch-n-Sketch is the 2016 direct-manipulation paper; IR4RL is evaluated on SVG/TikZ. These limited extensions do not imply coverage of the full graphics-programming field.
- VISTA v4 expands the benchmark to Web and Android. Its title block says Spec-to-App, while the abstract citation metadata retains Spec-to-Web-App and splits one author into two fields. The v4 title and six-person author list are used below.
- UICoder and WebUIProof start from text; their inclusion rests on visual training feedback, with execution-time visual assessment also present in WebUIProof. Pattern2Code is constrained completion with supplied HTML, not full-page generation.
- MaLiang-Harness is a graphics/animation system with revision-aware rendering and verification. It is a bounded adjacent connection, not evidence of frontend reconstruction performance.
- Official system documentation has D status and is not counted as a paper or formal technical report. All six open-source entries now have immutable README/license snapshots, including the previously unpinned screenshot-to-code entry.
- The open-source list is based on repository documentation rather than associated research claims. Supporting browser servers and source-location tools are explicitly distinguished from complete coding harnesses.
